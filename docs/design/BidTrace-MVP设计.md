# BidTrace（Bruce标迹）MVP 设计说明

> 版本：0.1.0  
> 状态：第一期已落地骨架

## 产品

投标部局域网共用台账：平台账号、询标报名、用户/权限。风格与技术对齐 BruceAgent 独立站。

## 角色与权限

| 角色 | 默认要点 |
|------|----------|
| admin | 全开 |
| leader | 业务全开，密码脱敏，无用户管理 |
| inquiry | 询标全开，平台只读 |
| member | 询标可写，平台只读 |

管理员可对单人覆盖任意权限码（见 `apps/api/permissions.py`）。
